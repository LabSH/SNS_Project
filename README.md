# 💬 SNS 서비스 개발
블로그(게시판) 형식과 채팅 프로그램을 융합한 것이 SNS의 핵심이라고 생각했습니다.
이에 따라, 양방향 통신에 대해 학습하고, 백엔드 기능 구현에 적합한 게시판 기반의 SNS 서비스를 직접 제작해보고자 했습니다.
단순한 CRUD 기능뿐만 아니라 실시간 메시징 기능까지 포함시켜, 실전에서 사용되는 기술들을 통합적으로 경험할 수 있는 프로젝트를 목표로 삼았습니다.

# 🎯 프로젝트 목표
- **Spring Boot 기반 SNS 서비스 개발**: Spring 프레임워크의 의존성 주입, JPA 등 핵심 개념을 학습하며 확장 가능한 백엔드 구조를 구축합니다.
- **Thymeleaf로 동적 웹 페이지 구현**: 서버 사이드 렌더링(SSR)을 통해 사용자 친화적인 동적 UI를 제공하며 Thymeleaf의 템플릿 엔진 활용법을 익힙니다.
- **MVC 패턴 설계**: Model-View-Controller 패턴을 적용해 코드의 유지보수성과 가독성을 높이는 구조적 설계를 추구합니다.
- **실시간 채팅 기능 구현**: Spring WebSocket을 활용해 저지연 실시간 통신을 제공하여 사용자 간 원활한 소통 환경을 구축합니다.


# 💻 기술 스택
- OS: macOS
- DBMS: `MySQL`
- 개발 도구: `IntelliJ`
- 주요 기술: `Java` `Spring Boot` `JPA` `JavaScript` `HTML` `Thymeleaf`
  
👥 프로젝트 작업인원: 개인 프로젝트

🗓️ 프로젝트 완료일: 2025-02-01

# 🛠️ 주요 기능 및 특징
- **실시간 1:1 메시징 기능:** Javascript의 STOMP 라이브러리와 Spring WebSocket을 이용해 사용자 간 실시간 메시지 송수신 기능을 구현했습니다.
- **사용자 세션 관리:** 실시간 원할한 양방향 통신을 위해 Principal 객체를 활용하여 사용자 세션을 관리하고 사용자를 구분했습니다.
- **동적 데이터 처리:** Thymeleaf를 활용하여 서버에서 전달된 데이터(Object, Model)를 동적으로 처리하고 웹 페이지에 렌더링했습니다.
- **데이터베이스 연동:** JPA(Java Persistence API)를 기본으로 사용하며, 필요에 따라 NativeQuery를 직접 작성하여 복잡한 쿼리 처리와 동시에 SQLInjection 방지를 했습니다.

# 🔍 문제 해결 및 사례
- Spring Boot 기반 개발: 처음 접하는 Spring Boot 프로젝트라 처음에는 많이 방황했습니다. 하지만 Spring 관련 자료가 풍부하여 블로그, 오픈소스, 유튜브 등 다양한 채널에서 정보를 적극적으로 찾아 공부했고, 개발 환경을 잘 셋팅할 수 있었습니다. 배울 때마다 중요한 내용을 메모장에 정리하며 잊지 않고 자신의 것으로 만들기 위해 꾸준히 노력했고, 그 결과 프로젝트를 성공적으로 완성할 수 있었습니다.
- **실시간 1:1 메시징 기능:** 처음에 WebSocket을 사용할 때 단지 Spring WebSocket 라이브러리만 사용하면 되는 줄 알았습니다. 하지만 JavaScript의 STOMP 라이브러리를 함께 사용해야 메시지 프레임워크를 간편하게 관리할 수 있고, 메시지 전송과 구독을 효율적으로 처리할 수 있다는 것을 알게 되었습니다. 이를 통해 클라이언트와 서버 간 양방향 통신을 안정적으로 구현할 수 있었습니다.
- **사용자 세션 관리:** 처음 개발할 때에는 단지 HttpSession을 사용해 세션을 등록했습니다. 하지만 그것만으로는 사용자마다 고유한 세션을 효과적으로 관리하기 어려웠고, 실시간 채팅 기능에서 사용자 식별이 제대로 이루어지지 않는 문제가 발생했습니다. 이를 해결하기 위해 Principal 객체를 활용하여 로그인한 사용자의 정보를 기반으로 세션을 명확하게 식별 및 관리할 수 있도록 개선하였습니다.

# 📚 성과 및 배운 점
- **주석의 중요성:** 개발을 진행하다 보면 시간이 지나면서 자신의 코드가 이해하기 어려워지거나, 특정 부분의 역할이 헷갈릴 때가 있습니다. 이럴 때 주석이 큰 도움이 된다는 것을 깨달았습니다. 특히 TODO를 활용해 구현 예정인 부분을 명확히 표시함으로써, 프로젝트 진행 상황을 체계적으로 관리할 수 있었습니다.
- **Spring Boot와 개발 환경 셋팅의 중요성:** 처음 접하는 Spring Boot 프로젝트를 진행하면서, 개발 환경 구성과 프레임워크의 기본 개념을 이해하는 데 많은 시간이 필요하다는 것을 깨달았습니다. 다양한 온라인 자료와 커뮤니티를 적극 활용해 문제를 해결하며, 체계적인 학습법과 꾸준한 기록의 중요성을 실감했습니다.
- **양방향 통신과 WebSocket, STOMP의 이해:** 실시간 1:1 메시징 기능을 구현하는 과정에서 단순히 Spring WebSocket만 사용하는 것이 아니라, JavaScript의 STOMP 라이브러리를 함께 사용해야만 안정적이고 효율적인 메시지 송수신이 가능하다는 점을 배웠습니다. 이를 통해 실시간 통신의 구조와 프로토콜에 대한 이해를 높일 수 있었습니다.
- **사용자 세션 관리의 필요성과 Principal 활용:** HttpSession만으로는 복수 사용자 환경에서 세션 관리를 완벽히 할 수 없다는 문제를 경험했고, Principal 객체를 활용해 사용자 인증 정보를 기반으로 세션을 명확히 구분하는 방법을 학습했습니다. 이를 통해 실시간 서비스에서 사용자별 상태 관리를 효과적으로 구현할 수 있음을 알게 되었습니다.
- **백엔드 아키텍처 설계와 MVC 패턴의 실무 적용:** Model-View-Controller 패턴을 프로젝트에 적용하면서 유지보수성과 코드 가독성을 높이는 설계 방법을 몸소 체험했습니다.
