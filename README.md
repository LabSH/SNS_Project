# 📝 개인 프로젝트: SNS 서비스 개발
🗓️ 프로젝트 완성 일시: 2025-02-01

# 💻 기술 스택
- OS: macOS
- DBMS: MySQL
- 개발 도구: IntelliJ
- 주요 기술: Java, Spring Boot, JPA, JavaScript, HTML, Thymeleaf
# 🎯 프로젝트 목표
- Spring Boot 기반 SNS 프로그램 개발: Spring 프레임워크의 기본적인 개념과 활용법을 익히는 데 중점을 둡니다.
- Thymeleaf 학습: 서버 사이드 템플릿 엔진인 Thymeleaf의 기초를 학습하고 동적인 웹 페이지를 구현합니다.
- MVC 패턴 적용: Model-View-Controller(MVC) 디자인 패턴을 적용하여 프로젝트 구조를 설계하고 개발합니다.
- WebSocket 채팅 프로그램 구현: WebSocket을 활용하여 실시간 채팅 기능을 구현합니다.
# ✨ 주요 기능 및 특징
- 실시간 1:1 메시지 기능: WebSocket을 이용해 사용자 간 실시간 메시지 송수신 기능을 구현했습니다.
- 사용자 세션 관리: Principal 객체를 활용하여 사용자 세션을 효율적으로 관리하고 사용자를 구분합니다.
- 동적 데이터 처리: Thymeleaf를 활용하여 서버에서 전달된 데이터를 동적으로 처리하고 웹 페이지에 렌더링합니다.
- 유연한 데이터베이스 연동: JPA(Java Persistence API)를 기본으로 사용하며, 필요에 따라 NativeQuery를 직접 작성하여 복잡한 쿼리도 유연하게 처리했습니다.
