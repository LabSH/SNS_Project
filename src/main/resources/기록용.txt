[th:utext] HTML 태그를 해석하여 렌더링하는 속성. 반면 th:text는 HTML 태그를 문자 그대로 출력해.

th:utext	HTML 태그를 해석하여 렌더링	    <b>굵은 글씨</b>	굵은 글씨
th:utext는 HTML을 해석하므로, 사용자가 입력한 값을 그대로 출력하면 XSS(크로스 사이트 스크립팅) 공격에 취약

th:utext → HTML 태그가 적용되어야 하는 경우 사용 (ex: 게시판 내용, 공지사항 등)은 사용해도 딱히 관계없음
